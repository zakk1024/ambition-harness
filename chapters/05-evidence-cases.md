# 05 · 案例庫使用規則（chapters/05-evidence-cases.md）

> 資料本體在 references/exemplars.md（種子五例＋入庫欄位契約）；本檔只寫使用規則。兩檔互為鏡像。

## 使用規則

1. **體裁檢索**：以當前任務比對案例的體裁標籤，取 1–2 例。不多引——範例是 context 稅（ADR-9）。
2. **先例效應是燃料不是方法**：案例校準「可行性判斷與野心規模」，不替代章 01 編譯與章 02 驗證；
   引例必附其效度欄與三值判定，只講故事的引用不合規。
3. **無驗證欄不得入庫**：新案例須齊五欄位——三件組、效度數據（無則標「待補測」）、三值判定
   （PASS／FAIL／UNVERIFIED）、體裁標籤、校準註記（傳說級必附）——表頭照 exemplars.md。
4. **範例缺口回饋**：檢索落空（無體裁相近例）時，在 exemplars.md「範例缺口」節記一行：
   需要什麼體裁／為何落空／日期。下輪入庫以此為準；不得為湊數放寬入庫欄位。
5. **敘事錨引用紀律**：傳說級案例（如 Dantzig）引用時校準註記隨行——一次性入庫成本、引用邊際成本近零
   （S3 裁決 2）。加引號僅限已核逐字句（引言紀律：宣稱、出處、逐字核三者齊，才加引號）。
